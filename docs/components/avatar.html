Avatar

Represents a user, entity, or system identity. Use a profile image or initials. Common in navigation, tables, timelines, and collaborative surfaces.

Sizes & shapes

Six sizes: X-Small (26px), Small (40px), Medium (48px), Large (64px), X-Large (82px), XX-Large (128px). Two shapes: circle and rounded square.

Avatar group

Stack multiple avatars with overlap; leftmost on top. Use a flex container and negative margin on all but the first avatar. Add ring-2 ring-white so overlaps read clearly. Three sizes: Default (medium), Small, Extra Small.
