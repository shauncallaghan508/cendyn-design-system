Badges

Visual indicators for short labels and counts. Use for statuses, categories, or metadata on tables, dashboards, and cards. Read-only.

Colors

Five colors, each with a solid and a soft variant. Padding px-3 py-1 (12px / 4px), rounded-badge, 12px Semibold.

Badge status

Status indicator: colored dot (8px) plus optional label. Use 14px body text (Book), dark label color. Gap between dot and label: 8px.

Label Label Label

Dot color: Success bg-success-100, Danger bg-error-100, Warning bg-warning-100.
