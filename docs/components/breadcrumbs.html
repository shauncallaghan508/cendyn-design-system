Breadcrumbs

Secondary navigation that shows location in a hierarchy and lets users move back. Use with primary nav, not instead of it.

Single item

Breadcrumb text must use heading-6-caps: text-heading-6-caps (10px Semibold, 8% letter-spacing). One item = link (or span for current page) + caret. Use breadcrumb-item to wrap the link: it adds the caret via ::after so the caret keeps a fixed 16px size and isn’t stretched by the link’s border. Label color text-neutrals-gray-700; caret is gray-500, 16px.
