Code

Use a single class per button: btn-solid-primary, btn-outline-secondary, btn-link-primary, etc. Add btn-sm for small text buttons or btn-icon-sm for small icon-only. Disabled and focus states are built in.

<!-- Solid -->
<button type="button" class="btn-solid-primary">Button</button>
<button type="button" class="btn-solid-primary btn-sm">Small</button>

<!-- Outline -->
<button type="button" class="btn-outline-primary">Button</button>

<!-- Link -->
<button type="button" class="btn-link-primary">Button</button>

<!-- Icon only -->
<button type="button" class="btn-icon-solid-primary" aria-label="Add">
  <svg class="icon-sm" viewBox="0 0 16 16" fill="none" stroke="currentColor" stroke-width="1.5">...</svg>
</button>

<!-- Split -->
<span class="btn-split"><button type="button" class="btn-split-main-primary">Button</button><button type="button" class="btn-split-trigger-primary"><svg class="icon-sm">...</svg></button></span>
