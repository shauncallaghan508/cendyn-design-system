Calendars

Date picker, date range, and full-page month calendar. Class names use the calendar-* prefix. Picker/range use a 240px-wide body and row-based date grid (7×6, 24×24px cells, 12px gap). Full-page view fills the viewport with a bordered grid and can be opened in a new tab.

Full page calendar

Month view that fills the viewport with a bordered grid, full weekday names (Sun–Sat), month/year header with prev/next and dropdown, and a “Return to Today” link. Matches Figma node 9247-55283. Open in a new tab to view at full size (pop out).

Classes: calendar-full, calendar-header, calendar-header-nav, calendar-month-dropdown, calendar-return-today, calendar-body. Grid uses grid-cols-7 with bordered cells.
