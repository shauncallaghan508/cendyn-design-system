Data Grid

Responsive data table with horizontal scrolling, sortable/filterable column headers, and pagination. Built from existing badges, avatars, tooltips, and scrollbar components. Long header or cell text is truncated with an ellipsis; hovering shows the full value in a tooltip.

Guidelines

  • The grid fills its container. Columns use fixed widths via colgroup; the table overflows horizontally and scrolls via overflow-x-auto on the wrapper. The global scrollbar styles apply automatically.
  • Header text is text-heading-6-caps (10px semibold uppercase). When a header label is too wide for its column, it is truncated with an ellipsis.
  • Cells that can overflow use truncate (overflow-hidden text-ellipsis whitespace-nowrap). On hover, a tooltip-ds shows the full text.
  • Reused components: Badges (status pills, LIVE badge, tags), Avatar (xs circle, avatar groups with -ml-2 ring-2 ring-white), Tooltip (tooltip-ds--placement-top), Icons (filter, link, chevron, direction arrows).
  • Pagination sits below the scrollable area so it is always visible. Active page uses bg-primary text-white.
