Dropdowns

Dropdown menus and selects.

Preview

Dropdown menu (Figma 7312-548): white panel, 160px wide, 8px radius, light border, three action items with 16px vertical gap.

Code

Use dropdown-menu for the panel and dropdown-menu-item for each action. Toggle visibility with JS (e.g. aria-expanded, hidden).

<div class="relative inline-block">
  <button type="button" class="btn-outline-secondary" id="dropdown-trigger" aria-haspopup="true" aria-expanded="false">Options ▾</button>
  <div class="dropdown-menu absolute top-full left-0 mt-2 z-10" role="menu" aria-labelledby="dropdown-trigger" hidden>
    <button type="button" class="dropdown-menu-item" role="menuitem">Action</button>
    <button type="button" class="dropdown-menu-item" role="menuitem">Action</button>
    <button type="button" class="dropdown-menu-item" role="menuitem">Action</button>
  </div>
</div>
