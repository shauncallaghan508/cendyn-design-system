Dropdowns

Dropdown menus and selects.

Preview

Dropdown with input-select trigger (Figma 7082-4061): select-style field with value + chevron. Panel: Figma 7312-548 — white, 160px wide, 8px radius, three action items.

Options

Use input-select for the trigger (or input-select-sm in tight layouts like card lists), dropdown-menu for the panel, dropdown-menu-item for each action. Toggle visibility with JS.
