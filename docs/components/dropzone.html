Dropzone

Dropzone allows users to upload content of their own (single or multiple files).

General usage

Guidelines

  • The user can click, or drag and drop the file to the zone to be uploaded.

Examples

Single file — default

Dashed border and text use neutrals-gray-600. Use class dropzone. Wire a hidden file input to the click area.

Single file — hover

On hover/focus, text uses neutrals-gray-800.

Single file — disabled

Disabled state: border and text neutrals-gray-400, cursor-not-allowed. Use disabled on the input or class dropzone-disabled on the label.

Image preview states

Same image (as filename-one) in three states: disabled (faded/desaturated), default (full color), hover (dark overlay with “Drag and drop or click to upload” in white).

Thumbnails

The thumbnail will vary depending on the file uploaded.

  • Image. Used when the user uploads an image (.jpg, .jpeg, .png, etc)

  • Icon. Used when the user uploads a Word file (.doc, .docx)

  • Icon. Used when the user uploads an Excel file (.xls)

  • Icon. Used when the user uploads a compressed file (.zip, .rar)

  • Icon. Used when the user uploads a PDF file, and also for all other options not included above. (.pdf, other)

Use dropzone for the empty area; dropzone-file-list, dropzone-file-item, dropzone-file-thumb, dropzone-file-info, dropzone-file-name, dropzone-file-size, dropzone-file-remove for the file list. Choose thumbnail: image preview for images, or icon by type (Word, Excel, zip, PDF/other).
