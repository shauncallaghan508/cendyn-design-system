Empty States

States convey to the user that no information / content is available.

General usage

Rules

  • Use when a container has no data but will eventually have it; CTAs are available to request data or let the user create an entry.
  • On cards: minimum 40px padding on all sides. If width is greater than height, center the empty state within the card.
  • On full page: position center–center in the container.

Structure

  • Icon — Graphic for the empty state; swappable. New graphics go on the “Illustrations and Avatars” page.
  • Title — Short title.
  • Description — Longer description, preferably up to three lines.
  • Actions — Up to two actions: one button, or a button and a link.
