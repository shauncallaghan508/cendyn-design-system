Inputs — general guidelines

A component used within forms in order to capture information. Figma 16955-145583.

Properties

Icon variants are available in different positions that can be replaced as needed.

  • Text. Used to capture a string/text.
  • Select. Used when a dropdown menu is needed.
  • Clear. Used when there is a need to clear the content on the input.
  • Icon Left. Used for visual reinforcement. Can indicate what the field is for such as a search.
  • Icon Right. Used for visual reinforcement (e.g. validation icon such as a check, or a calendar for a date picker).
  • Icon Left and Right. Typically used with chevrons for a date range or to navigate between elements.
  • Numeric. Lets the user specify a numeric value using arrow buttons.
  • Numeric with Unit. User can change the unit by clicking on it; a dropdown shows available options.
  • Search. Used when a search bar is needed. User can press Return to trigger search.
  • Status. Used for visual reinforcement (e.g. status).

Sizes

Size is chosen based on the space limitations.

  • Default. Should be used the majority of the time. If buttons are used, use default buttons.
  • Small. Can be used where space is limited (e.g. popovers). Use with small buttons if buttons are present.

Text state

States indicate whether the user has filled out the field or not.

  • Placeholder. Use when giving a hint (e.g. “Enter Address” or a suggested value). Placeholder text uses text-neutrals-gray-700.
  • Filled. Shows that the user has filled the field, or an override to the placeholder. Filled text uses text-neutrals-black. States and icons can accompany to reinforce the message.

Labels

  • Label. Should be used the majority of the time.
  • Required. When the field is required to complete (e.g. Label*).
  • Label + Help text. Use when short supplementary info brings clarity.
  • Label + Link. Use when a link is associated (e.g. “Help link?”).
  • Label with Badge. For status (e.g. “Complete”).

How inputs respond to interaction and validation. Figma 16958-145850.

Interaction states

Border steps from default (gray-400) → hover (gray-600) → focus (black + ring). Disabled uses gray-100 background and muted border/text.

Toggle

Switch control for binary choices. Track 40×22px, thumb 16px. States: default off (gray-400 track), default on (primary track), disabled off/on (opacity 60%; disabled on uses gray-600 track). Figma 16932-145649.

Layout variants

Toggle only (no label), label right (14px), or label left (14px). Use toggle, toggle__switch, toggle__label. Add toggle__switch--on for on state, toggle__switch--disabled or toggle--disabled for disabled.
