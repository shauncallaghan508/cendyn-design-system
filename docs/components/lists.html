Lists

List layouts and list items.

Card list

A bordered card with an optional header and rows of label/data pairs. Use for key-value lists (e.g. search filters, property lists). Header: 62px height, 24px horizontal padding. Rows: 48px height, label left (black), data right (gray-700).

Code (basic row)

<div class="card-list">
  <header class="card-list__header">
    <div class="card-list__header-content">
      <h3 class="card-list__header-title">Search</h3>
    </div>
  </header>
  <div class="card-list__list">
    <div class="card-list__item">
      <div class="card-list__item-row">
        <div class="card-list__item-content">
          <span class="card-list__item-label">Label</span>
          <span class="card-list__item-data">Data</span>
        </div>
      </div>
    </div>
    <!-- Data as link: add card-list__item-data--link to data span -->
    <!-- Status: use card-list__item-data-wrap with card-list__item-status-dot + data -->
    <!-- Toggle: use toggle component in data slot -->
    <!-- Button: use btn-solid-primary btn-sm -->
    <!-- Badge: use card-list__badge or card-list__badge--muted -->
  </div>
</div>
