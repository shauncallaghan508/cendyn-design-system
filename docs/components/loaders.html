Loaders

Loaders show that the system is working on a user-initiated task. Use spinners for short, indeterminate waits (Figma 33441-46824), and progress bars for longer operations with measurable progress (Figma 10259-57353).

Progress bars

Default (15px) and slim (5px) tracks with primary fill. Set fill width with inline style="width: …%" or a CSS variable. Use role="progressbar" with aria-valuenow, aria-valuemin, aria-valuemax.

Spinners

Default (32px) and small (20px) spinners with optional title and description. Rotation uses Tailwind animate-spin on .spinner__svg.
