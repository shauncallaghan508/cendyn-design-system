Modals & Dialogs

Modals surface information or ask for input related to the current task (Figma 7800-2). Dialogs are a focused type of modal for confirmations, warnings, or a required response before continuing (Figma 7685-41782). Both sit above the page and block the background.

Dialogs

400px max width, centered copy, no title bar or close icon. Use dialog, dialog__body, dialog__title, dialog__description, dialog__actions. The compose variant reuses compose-text-area with compose-text-area--dialog for the Figma 113px field height.

Modals

Responsive

Combine any size class with modal-responsive so the dialog is 100% width of its parent (fixed max-widths are overridden). It has auto height to fill any amount of content. Example is wrapped in a max-width container to show fill behavior.

Sizes

Four fixed widths: small (300×292px), default (500×300px), large (800×300px), x-large (1140×300px, capped to viewport). Apply modal--sm, modal--default, modal--lg, or modal--xl on .modal. Footer actions use btn-solid-secondary and btn-solid-primary.
