Scrollbar

Figma: 13789-64424

Scrollbars are styled globally in @layer base in docs/input.css (compiled into docs.css). Any element that scrolls—page, side panels, lists, tables—uses the same thumb and track treatment. Add overflow-y-auto or overflow-x-auto on the scroll container; no extra utility class is required.

Guidelines

  • Thumb: neutrals / gray-600 (#95AAC9) at 80% opacity (rgb(149 170 201 / 0.8)).
  • Shape: Fully rounded ends (pill) — border-radius: 100px on WebKit scrollbar thumb.
  • Track: Transparent so the content surface shows through; 8px scrollbar gutter (WebKit).
  • Hover (WebKit): Thumb opacity increases slightly for feedback.
  • Firefox: scrollbar-width: thin + scrollbar-color (thumb / transparent track).

Implementation

Rules target * so scrollbars are consistent everywhere. To ship the same behavior in an app that consumes this repo, include the compiled CSS or copy the scrollbar block from docs/input.css into your global styles.

<!-- Scroll container only: styling is global -->
<div class="max-h-60 overflow-y-auto">
  ...scrollable content...
</div>
