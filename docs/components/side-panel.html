Side Panel

Guidelines and sizes — 13886-87247; layout references — 13147-59798.

Guidelines

General rules

  • Can be closed with the close control (X) or by activating the dimmed overlay (outside the panel).
  • Overlay uses neutrals-black (#12263F) at 50% opacity — bg-neutrals-black/50.
  • The panel body can contain other components: cards, tables, buttons, lists, etc.

Size

Five widths aligned to the grid (Figma column counts and reference widths):

  • XS — 33.3% · 4 columns · max 467px — side-panel--xs
  • S — 41.7% · 5 columns · max 590px — side-panel--sm
  • M — 50% · 6 columns · max 710px — side-panel--md
  • L — 66.6% · 8 columns · max 953px — side-panel--lg
  • XL — 83.3% · 10 columns · max 1197px — side-panel--xl
