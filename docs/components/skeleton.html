Skeleton

Figma: 33307-89909 (rounded rectangle), 33307-89911 (circle).

Use skeleton blocks while content loads. The fill is a gradient from neutrals gray-300 to neutrals gray-200 (#e4ebf6 → #edf2f9), matching the spec. Rectangles use 8px corner radius; avatars and icon placeholders use the circle variant.

Rounded rectangle

Set width/height (or Tailwind w-* / h-*) on .skeleton.

Circle

Add .skeleton--circle for a circular placeholder (same gradient).

Composition

Typical text row: circle + stacked lines. Optional .skeleton--pulse adds a light pulse (not in Figma; use when you want motion).

Code

<div class="skeleton w-full h-24" aria-hidden="true"></div>
<div class="skeleton skeleton--circle w-12 h-12" aria-hidden="true"></div>

Prefer aria-busy or aria-live on the parent region when replacing skeletons with real content.
