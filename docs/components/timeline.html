Timeline

Figma — Timeline: 7076-30251 · Activity: 12937-63670

The Timeline component displays events related to an entity, user, or system in a defined order. Use the default Timeline variant for a vertical spine and connector between items. Use the Activity variant for a denser feed: row dividers, no connector, narrower max width (390px), and timestamp in gray-600. Avatar and dot markers are shown for both variants below.
