Toasts

Lightweight, transient notifications for system feedback without blocking workflow. Figma: 31855-25956.

Use .toast with .toast--basic (single row: icon, title, dismiss) or .toast--advanced (header strip + body copy + optional link). Max width 300px, rounded-xl, border-neutrals-gray-400, and Figma card drop shadows. Pair with role="status" or role="alert" and position fixed/stacked in your app shell.

Basic

One line: success-style icon (24px circle), text-line-2 title, 16×16 dismiss. Shadow: 0 2px 25px -8px rgb(18 38 63 / 15%).

Toast title

Advanced

Header row with text-heading-4 title, inset bottom rule (neutrals-gray-400), then body with text-paragraph-2 and optional .btn-link-primary. Shadow: 0 2px 25px 0 rgb(18 38 63 / 15%).
