Tree View

Hierarchical lists with search, expand/collapse, optional selection, links, badges, and bulk actions. Main anatomy: 10597-73499. Search field: 11006-76878 (uses input-group from Forms). Guidelines: 14001-90244 (multi-select), 31855-22186 (organization switcher). Data examples: 31917-1700. Item select (circle): 31816-1789.

When to use which pattern

Multi-select

Use when users may select multiple organizations or nodes. Supports parent/child selection and bulk helpers.

  • Select all appears when a parent has multiple selectable children, the parent is selected, and the user hovers the row (see Organizations A in Figma).
  • Unselect all appears when the parent is selected and all children are selected (see Organizations B).
  • Non-selectable rows omit the checkbox for read-only context (see Organizations C).

Single-select (Organization switcher)

One active organization; menu closes after choice.

  • User picks a Chain, Brand, or Property; flow continues after selection.
  • Selecting a Chain or Brand alone does not imply all children are selected.
  • No Select all / Unselect all in this mode.

Anatomy

Use .tree-view for the shell (search + scrollable list). Each row is .tree-item with indent gutter, expand control, optional .tree-item__select, title + uppercase meta line, and trailing actions: btn-link-primary (Buttons), primary solid badge classes (Badges), and btn-link-primary btn-sm for Select all / Unselect all (optional .tree-item__bulk hook for hover-reveal).

Markup notes

  • Use role="tree" / treeitem with proper aria-expanded when behavior is a true tree; for flat lists, role="listbox" or a simple list may be better.
  • Wire selection to aria-checked / aria-checked="mixed" for indeterminate and real inputs where forms require it. Use tree-item__select--checked, --unchecked, or --neutral (minus icon).
  • Subtitle uses design-system heading-6-caps treatment (10px, uppercase, gray-700).
  • Search bar: use input-group__field and input-group__input-wrap (see Forms — Icon left / search pattern).
  • Trailing link / bulk: btn-link-primary (and btn-sm for compact actions); status pill: primary solid badge classes from Badges — do not duplicate with custom tree-only styles.
