Wizard

Multi-step progress for long or complex workflows. The DOM matches the app wizard: ul.wizard-nav (role="tablist") → li.wizard-nav__step → a.wizard-nav__icon + h6.wizard-nav__title, with connectors drawn in CSS between steps. Use .header-wizard for the full-width header with title, back/next actions, and bottom rule. Design: 10259-57404. Pair actions with Buttons (btn-solid-default back, btn-solid-primary forward).

Anatomy

  • Completed — wizard-nav__step--completed on li: primary circle + visible check; label text-primary. Connector after this step is primary.
  • Current — active on li (same as production): primary ring, empty circle, label primary. Connector after is gray.
  • Upcoming — neither completed nor active: gray ring, hidden check, muted label. Connectors gray.
  • Titles use wizard-nav__title (text-heading-6-caps) with whitespace-nowrap so labels stay on one line and stay centered under the icon.

Markup notes

  • ul.wizard-nav with role="tablist"; each li.wizard-nav__step has role="presentation"; a.wizard-nav__icon with role="tab", aria-selected, and tabindex; h6.wizard-nav__title for the label (matches production).
  • Put active on the current li; add wizard-nav__step--completed on finished steps. Connectors are li:not(:last-child)::after — primary when the li is --completed, gray otherwise.
  • Optional wizard-nav--scroll on the list for min-w-[480px] in tight layouts. App shell may use hidden md:flex (or similar) on the list to mirror Bootstrap d-none d-md-flex.
