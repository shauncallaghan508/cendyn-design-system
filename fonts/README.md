# Font files

Design system fonts (Cerebri Sans) used by the preset. These files are published with the package.

**Current files:**

| File                     | Weight |
|--------------------------|--------|
| `cerebrisans-book.woff`   | 400    |
| `cerebrisans-regular.woff`| 400    |
| `cerebrisans-medium.woff`| 500    |
| `cerebrisans-semibold.woff` | 600  |
| `cerebrisans-bold.woff`  | 700    |

Paths in `../fonts.css` reference these filenames. If you add or rename files, update `fonts.css` to match.
